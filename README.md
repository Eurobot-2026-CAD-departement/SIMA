# SIMA

CAD and electronics for the **SIMA** and **PAMI** robots and related designs.

## Contents
- `PAMI 3.0/`, `PAMI 3.0 final/`, `PAMI finalll/` — PAMI iterations (the largest assembly, `PAMIIII.SLDASM`, is stored with Git LFS), including base, cover, mechanism support and 3D printing files
- `SIMA container/`, `SIMA arrangement/` — SIMA container and arrangement/support parts
- `sheild esp pami ninja/` — KiCad shield (ESP32) for the PAMI / Ninja
- `NINJA CAD/`, `ninja/` — Ninja robot CAD, `piece util`, gripper and cutting files
- `pami/` — PAMI parts (e.g. small encoder wheels)

---

Part of the CAD work of the **Aerobotix (INSAT, Tunisia) Eurobot 2026 team** — see the [organization](https://github.com/Eurobot-2026-CAD-departement) for the other repositories.
